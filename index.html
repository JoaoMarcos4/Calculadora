Calculadora de Bases Numéricas

Manual de Instruções: Calculadora de Bases Numéricas

Use apenas os botões da tela para digitar. O teclado do seu computador está desativado para este display.

Conversão de Base

Digite no formato: número(base_origem). Exemplo: 1010(2) para binário ou A(16) para hexadecimal.

Em seguida, clique em um dos botões do topo (bin, oct, dec, hex) para ver o resultado da conversão abaixo do display.

Contas Matemáticas

As operações ocorrem somente entre números na base decimal.

Digite o primeiro número, escolha a operação (+, -, *, /), digite o segundo número e clique em = para calcular.

Limpar Tela

Clique no botão AC a qualquer momento para apagar todo o display e resetar o histórico.
